Settings

Provider & model

Lime works with every OpenAI-compatible API, plus Anthropic and Gemini. The key is stored in your browser and in the app’s local backup; it is never sent anywhere except the selected provider.

No key needed — the built-in Lime Engine works offline: it generates 5 project types, modifies existing projects, answers technical questions and searches the web.

Agent behavior

Control what the agent can write and run without approval.

Action protocol — the agent writes with <file path="…">, deletes with <delete>, runs commands with <shell> and calls MCP with <mcp tool="…">. This format works even with models that do not support function calling.

MCP servers

Model Context Protocol: connect external tools (files, databases, GitHub, browser…). Transports stdio (local command) and http (Streamable HTTP).

Create your own theme — tutorial summary
  1. Open public/css/app.css: each theme combines a palette and a light or dark tone.
  2. Create a :root[data-palette="my-theme"] block and redefine the colors, including --accent, --accent-rgb and --accent-gradient.
  3. In public/js/themes.js, add the preset to THEME_PRESETS; the gallery renders it automatically.
  4. Give it a gradient preview, then check the selected state, the sun / moon pair and contrast in both tones.
  5. Check both tones, the 3D switch and contrast, then reload: the choice should persist.
:root[data-palette="my-theme"] {
  --bg: #101014;
  --panel: #17171d;
  --accent: #7c8cff;
  --accent-rgb: 124, 140, 255;
  --accent-gradient: linear-gradient(135deg, #a99dff, #5a48c9);
  --line: #2a2a34;
}

Lime AI v1.0.3

Local coding agent: the action loop of Claude Code, the instant preview of bolt.new.

  • Multi-API — OpenAI, OpenRouter, Groq, Mistral, DeepSeek, xAI, Together, Anthropic, Gemini, Ollama, LM Studio, vLLM…
  • MCP — stdio and HTTP servers, tools exposed to the agent.

The terminal and the agent run real shell commands. Never run Lime on a project you would not trust an AI with, and keep HOST=127.0.0.1 to stay local.

Welcome to Lime AI

Connect a model, or don’t

Without a key, the local Lime Engine generates sites, to-do apps, calculators, games and weather apps. With a key (Settings → AI connection), you unlock GPT, Claude, Gemini, Ollama…

Choose PC or Cloud

PC writes to a real folder through the Node server. Cloud writes to an internal Lime AI folder and offers a ZIP export.

See the result

The Preview / Code toggle switches from the app to the code (files, terminal, console, log). The preview refreshes after every file.

Talk to it

The microphone dictates your prompt, the speaker reads responses aloud. Everything uses browser APIs.

Good to know

  • A framework project (React, Vue…) does not render as-is: run npm install then npm run dev in the Terminal, and put the dev server URL in the preview bar.
  • MCP servers are configured in Settings → MCP servers, with a command and its arguments.
  • Cloud mode writes files to data/cloud, an internal Lime AI folder: they are available in the editor, terminal and ZIP, without appearing in your folders.
