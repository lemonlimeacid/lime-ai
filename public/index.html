Fournisseur & modèle

Supernova parle à toutes les API compatibles OpenAI, plus Anthropic et Gemini. La clé est conservée dans ton navigateur et dans la sauvegarde locale de l’application ; elle n’est jamais envoyée ailleurs qu’au fournisseur choisi.

Sans clé — le Supernova Engine embarqué fonctionne hors ligne : il génère 5 types de projets, modifie l’existant, répond aux questions techniques et cherche sur le web.

Comportement de l’agent

Contrôle ce que l’agent peut écrire et exécuter sans validation.

Protocole d’action — l’agent écrit avec <file path="…">, supprime avec <delete>, exécute avec <shell> et appelle MCP avec <mcp tool="…">. Ce format fonctionne même avec les modèles sans function calling.

Serveurs MCP

Model Context Protocol : connecte des outils externes (fichiers, base de données, GitHub, navigateur…). Transports stdio (commande locale) et http (Streamable HTTP).

Style de thème

Le style se combine avec le mode clair ou sombre choisi par le bouton soleil / lune de la barre supérieure.

La dictée repose sur la Web Speech API : Chrome et Edge la prennent en charge nativement, Firefox ne supporte pas encore la reconnaissance vocale (la lecture, elle, fonctionne partout).
Créer ton propre thème — résumé du tuto
  1. Ouvre public/css/app.css : tout le thème est piloté par les variables de :root (fonds, texte, accent, bordures, ombres).
  2. Crée un bloc :root[data-style="mon-theme"] et redéfinis les variables utiles, y compris le relief (--elev-1, --edge-light, --window-elev).
  3. Ajoute une option dans le menu #themeSelectMenu (un bouton data-theme-style).
  4. Dans public/js/settings.js, applique le choix avec document.documentElement.dataset.style = value et enregistre-le avec saveSettings({ themeStyle: value }).
  5. Teste le thème en clair et en sombre, vérifie les contrastes, puis recharge : le choix doit rester.
:root[data-style="mon-theme"] {
  --bg: #101014;
  --panel: #17171d;
  --accent: #7c8cff;
  --line: #2a2a34;
}

Bienvenue dans Supernova IA

Branche un modèle, ou pas

Sans clé, le Supernova Engine local génère des sites, to-do, calculatrices, jeux et apps météo. Avec une clé (Paramètres → Connexion IA), tu débloques GPT, Claude, Gemini, Ollama…

Choisis PC ou Cloud

PC écrit un vrai dossier via le serveur Node. Cloud écrit dans un dossier interne à Supernova IA et propose un ZIP.

Regarde le résultat

La bascule Aperçu / Code passe de l’app au code (fichiers, terminal, console, journal). L’aperçu se rafraîchit à chaque fichier.

Bon à savoir

  • Un projet framework (React, Vue…) ne s’affiche pas tel quel : lance npm install puis npm run dev dans le Terminal, et mets l’URL du serveur de dev dans la barre d’aperçu.
  • Les serveurs MCP se configurent dans Paramètres → Serveurs MCP, avec une commande et ses arguments.
  • Le mode Cloud écrit les fichiers dans data/cloud, un dossier interne à Supernova IA : ils sont disponibles dans l’éditeur, le terminal et le ZIP, sans apparaître dans tes dossiers.
